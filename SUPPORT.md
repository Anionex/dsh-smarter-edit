# Support

- **Bugs:** use the [bug report](https://github.com/Anionex/dsh-apply-patch/issues/new?template=bug.yml) and include package, DSH, provider, and Node.js versions plus a minimal patch.
- **Feature requests:** use the [feature request](https://github.com/Anionex/dsh-apply-patch/issues/new?template=feature_request.yml).
- **Questions:** search existing issues first, then use the [question form](https://github.com/Anionex/dsh-apply-patch/issues/new?template=question.yml).
- **Security:** follow [SECURITY.md](SECURITY.md). Never post vulnerabilities, credentials, or private source in an issue.

Issues and pull requests are handled by the maintainer on a best-effort basis;
there is no support service-level agreement. The supported release is the
latest npm version of `@anionex/dsh-apply-patch`.
